// ДЕМО-ИСТОРИЯ для приложения «Переписки с Ирой»
// Приёмы Елены Райтман (из разборов в папке Елена_Райтман):
// 1) начало сразу с «дыры»: кто написал Ане?
// 2) у монстра понятное правило («не отвечай ей») – от этого напряжение
// 3) шутник Макс разряжает страх, перед страшным спокойный момент
// 4) подруга что-то скрывает (удалённое сообщение) – «знакомый не тот, кем кажется»
// 5) обе концовки кончаются новым вопросом, а не криком
// 6) смягчено для подростков: никто не пострадал «на экране», только «исчез», «покинул чат»

Название: Без имени
Описание: Ночью в чат друзей вступает тот, кого никто не звал
Чат: Ночные совы 🦉
Аватар чата: совы.jpg
Тип: группа
Я: Ника

Персонажи:
- Ника | цвет: #64B5F6 | аватар: Ника.jpg | о себе: Не сплю, потому что не могу 🌙
- Аня | цвет: #FF8A65 | аватар: Аня.jpg | о себе: Лучшая подруга Ники. Боится темноты | доверие: 6
- Макс | цвет: #81C784 | аватар: Макс.jpg | о себе: Шучу, когда страшно | доверие: 5
- Без имени | цвет: #E53935 | аватар: нет | о себе: ... | доверие: 0


== начало ==
[дата Сегодня]
[время 23:52]
Аня: Ника, ты не спишь? 😰
Макс: Я сплю. Мне снится, что я пишу в чат 😴
Аня: Макс, не смешно. Мне сейчас написал незнакомый номер
Аня: [фото сообщение_незнакомца.jpg] «Я вижу свет в твоём окне»
? Решить, что это прикол -> начало_свет
  текст: Может, кто-то из класса прикалывается?
? Спросить про свет в окне -> начало_свет
  текст: Аня, а у тебя правда свет горит?


== начало_свет ==
Аня: У меня свет выключен уже час...
Макс: Это как в легенде про Тень. Главное правило: **никогда ей не отвечать** 👻
// закреплённое сообщение висит под шапкой до конца истории
[закрепить Макс]
// правило монстра: зритель теперь боится, что кто-то ответит
[время 23:58]
[звук помехи]
[эффект помехи]
[система «Без имени» вступил(а) в чат]
[печатает 4]
Без имени: Ника. Ты ведь тоже не спишь.
[звук сердце]
[реакция Аня 😱]
? Ответить ему (написать незнакомцу) -> ответила
  текст: Кто ты? Как ты попал в наш чат?
  запомнить: ответила_тени
  доверие: Аня -1
? Аня, удали его! (попросить Аню выгнать его из чата) -> удалить
  текст: Аня, ты админ, удали его быстрее!
  доверие: Аня +1


== ответила ==
[печатает 3]
Без имени: Спасибо, Ника. Теперь я знаю, где ты.
Аня: [ответ Ника] НИКА! Зачем?! Макс же сказал правило!
Макс: Без паники. Я живу в соседнем доме, сейчас выгляну в окно
-> окно


== удалить ==
[система Аня удалила «Без имени» из чата]
Аня: Всё, удалила 😮‍💨
[звук уведомление]
[система «Без имени» вступил(а) в чат]
Без имени: Меня нельзя удалить.
Макс: Так. Я живу в соседнем доме, сейчас выгляну в окно
-> окно


== окно ==
// фон чата меняется на фото подъезда
[фон подъезд.jpg]
[время 00:03]
[звук шаги]
Макс: Девочки... у подъезда Ники кто-то стоит
Аня: [удалено]
? Спросить, что Аня удалила -> окно_удалено
  текст: Аня, что ты написала и удалила?
? Попросить Макса посмотреть в окно -> окно_удалено
  текст: Макс, кто там? Опиши


== окно_удалено ==
Аня: Ничего! Ника, просто не подходи к окну. Пожалуйста.
// здесь зритель начинает подозревать Аню
? Поверить Ане (не подходить к окну) -> не_подходить
  текст: Хорошо. Не подхожу 😟
  доверие: Аня +1
? Макс, сфоткай его (попросить Макса сфотографировать) -> фото
  текст: Макс, сфоткай его, я хочу увидеть
  доверие: Макс +1, Аня -1


== не_подходить ==
Аня: Спасибо, что веришь мне
? Успокоить Аню -> развязка
  текст: Я с тобой. Мы справимся вместе 💪
? Спросить, что она удалила -> развязка
  текст: Я тебе верю. Но что ты удалила?


== фото ==
// скрытое фото: размыто, открывается нажатием – со страшным ударом
Макс: [фото скрыто! подъезд.jpg] Вот. Видите?
Макс: Стоп. Он смотрит не на твоё окно. Он смотрит на МОЁ.
[вибрация 600]
[реакция Аня 😱]
-> развязка


== развязка ==
// концовка зависит от доверия к Ане (начало 6, каждый выбор +1 или -1)
если доверие Аня >= 6 -> признание
-> на_одного_меньше


== признание ==
[печатает 5]
Аня: Ника, я должна признаться
Аня: Тень написала мне неделю назад. Её правило: ||!приведи в чат друга, и она отстанет||
Аня: Я не думала, что она правда придёт 😭
если ответила_тени: Без имени: Ника сама мне ответила. Уговор выполнен, Аня.
если не ответила_тени: Без имени: Уговор выполнен, Аня.
[система «Без имени» покинул(а) чат]
[звук стук]
[эффект тряска]
Аня: Ника... кто-то стучит в мою дверь.
[конец Концовка «Уговор»]


== на_одного_меньше ==
[звук гул]
Макс: Ника, он идёт к моему подъезду
Макс: [удалено]
[система Макс покинул(а) чат]
[эффект вспышка]
[время 00:07]
Без имени: В чате стало на одного меньше. Кто следующий, Ника?
// сообщение меняется прямо на глазах
[изменить Без имени: Следующая – ты.]
Аня: Ника... Макс не берёт трубку
[конец Концовка «На одного меньше»]
