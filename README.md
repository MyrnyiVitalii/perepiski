# Переписки с Ирой

Веб-приложение для Android: интерактивные чат-истории в стиле мессенджера. Сообщения появляются по одному тапу, в нужных местах история даёт выбор, от выборов зависит доверие персонажей и концовка.

- Работает полностью в браузере, без сервера и регистрации.
- Истории, картинки и прогресс хранятся только на телефоне.
- Работает без интернета: после первого открытия всё приложение и все истории сохраняются в телефон (`sw.js`).
- Переписку можно удалить свайпом влево (только на этом телефоне); «Избранное» – заметки для себя.
- Формат файла истории: [ФОРМАТ_ИСТОРИИ.md](ФОРМАТ_ИСТОРИИ.md).
